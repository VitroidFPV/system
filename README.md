# System

## Human Part

This repository contains guides/assets for configuring my various systems, some made by me and some by an LLM, automatically generated by an LLM. The guides document specific changes, and assets contain shared files that are currently in use.

The guides are written to be readable by both humans and the machines.

## LLM Part

These guides record machine changes found in our threads through 25 October 2026. Each guide gives the files, actions, and a check to run on another Fedora KDE system. Replace machine names, paths, and account IDs where needed. The `assets/` directory contains the longer files used by some guides.
